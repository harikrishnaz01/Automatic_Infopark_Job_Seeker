# Automatic_Infopark_Job_Seeker
An automatic Python jon seeker site that specifically targets - INFOPARK JOB PORTAL(KOCHI) and scrapes the required jobs from it.


We all know how time consuming the process of looking at each company site in the infopark job site is, so to automate the process and make it easy on the ourselves. I have made this lil side project that scrapes from the website and outputs a csv file that contains all the job listings made on it. I have included an example file of how the input would look in here. 

NOTE: You can search for different jobs by typing in your required job specific terms
